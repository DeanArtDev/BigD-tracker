# 0004. Хранить архитектурную документацию как код

Статус: Принято

Дата: 2026-04-08

## Контекст

Диаграммы, которые существуют только в графических редакторах, быстро расходятся с кодовой базой и плохо подходят для изменений через pull request.

Для этого проекта нужно, чтобы архитектурная документация:

- хранилась рядом с кодом
- проходила code review
- была пригодна для визуализации
- была удобна для AI-агентов

## Решение

Хранить архитектуру как код:

- основной формат: `Structurizr DSL`
- дополнительный формат для быстрого просмотра: `Mermaid` в Markdown

## Последствия

Плюсы:

- архитектура версионируется вместе с кодом
- изменения можно ревьюить как обычные diff
- визуализация получается из текстового источника
- AI-агенты могут опираться на стабильную файловую структуру

Минусы:

- команду нужно приучить обновлять документацию вместе с изменениями архитектуры
- требуется минимальная дисциплина по поддержанию source of truth
