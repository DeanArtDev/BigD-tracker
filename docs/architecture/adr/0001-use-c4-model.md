# 0003. Использовать C4 как базовую модель архитектурной документации

Статус: Принято

Дата: 2026-04-08

## Контекст

Нужно поддерживать архитектурную документацию для frontend, BFF и backend-взаимодействий так, чтобы:

- её можно было читать без погружения во весь код
- её можно было обновлять вместе с кодовой базой
- она была пригодна и для людей, и для AI-агентов

## Решение

Использовать C4 как базовую модель архитектурного описания:

- `System Context`
- `Container`
- `Dynamic` для ключевых сценариев

## Почему

- C4 дает понятные уровни абстракции
- модель хорошо подходит для frontend + BFF + distributed system
- диаграммы остаются инженерно полезными и не перегружаются деталями реализации

## Последствия

- документацию проще поддерживать эволюционно
- обсуждения архитектуры становятся более предметными
- детали уровня кода остаются в репозитории, а не в диаграммах
